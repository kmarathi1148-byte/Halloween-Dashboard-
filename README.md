🎃 Dashboard Overview

This project is an interactive Halloween Visitor Analysis Dashboard created using Tableau. It analyzes Halloween visitor data from 2008 to 2014 to identify trends, patterns, and variations in visitor counts.

Dashboard Objective

The main objective of this project is to analyze yearly Halloween visitor data and identify useful trends and patterns through interactive data visualization and forecasting.

Dashboard Features

- Interactive visualizations
- Line charts and bar charts
- Year-wise visitor analysis
- Comparison of visitor counts across different years
- Analysis of yearly variations in visitors
- Forecasting of future visitor trends
- Easy-to-understand visual representation of visitor data

Key Insights

- Visitor counts increased steadily from 2008 to 2011.
- 2011 recorded the highest number of visitors during the analyzed period.
- Visitor numbers declined significantly in 2013.
- Visitor counts showed a slight recovery in 2014.
- The dashboard uses forecasting to identify possible future visitor trends.
- Year-by-year comparison helps identify fluctuations and changes in Halloween visitor patterns.
